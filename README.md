## 🗳️ Decentralized Voting System Using Blockchain
A secure and transparent blockchain-based voting system that ensures fairness, eliminates tampering, and maintains voter privacy. This project leverages the power of Ethereum smart contracts to enable safe, decentralized, and verifiable elections.
